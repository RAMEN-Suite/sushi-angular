# SUSHI

simple replacements
```
suiButton              replaces primeng/button
suiBadge               replaces primeng/badge
suiDivider             replaces primeng/divider
suiSpinner             replaces primeng/progressspinner
suiImage / suiFigure   replaces primeng/image
suiCard / suiPanel     replaces primeng/panel, fieldset
suiInput               replaces primeng/inputtext
suiFormField           replaces primeng/iftalabel
```
