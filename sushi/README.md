# @sushi-kit/angular

Accessible, themeable Angular components with typed signal APIs.

```bash
npm install @sushi-kit/angular
```

Import the global component styles once:

```css
@import '@sushi-kit/angular/sushi.css';
```

Documentation, examples, contribution guidance, and source are available in the [SUSHI KIT repository](https://github.com/sebenns/SUSHI).
