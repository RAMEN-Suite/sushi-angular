Form Field

Keep labels on the control border by default and enable floating motion only when the interaction benefits from it.

Label on the control

The default label remains visible on the border. It never competes with the entered value and requires no placeholder trick.

The label remains available after a value is entered. 
<div suiLabel>
  <label suiFormFieldLabel for="name">Display name</label>
  <input suiInput id="name" placeholder="Ada Lovelace" />
</div>

Optional floating label

Add floating when the label should begin in the value position and move onto the border on focus or content.

Conventional label

suiFormField keeps the label in normal document flow when no compact treatment is wanted.

Visible to everyone in the workspace.
