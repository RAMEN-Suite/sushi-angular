Toggle Button

Use sui-toggle-button for binary states represented as a button. Toggle buttons support labels, custom templates, severities, variants, sizes, shapes, disabled and loading states, two-way binding, and Angular forms.

Basic usage

The default labels are Off and On. The current state is exposed through aria-pressed. A checked toggle keeps the selected color and variant and uses a persistent pressed surface instead of changing outline or opacity.

Bound state: {{ isEnabled() }} 

<sui-toggle-button />
<sui-toggle-button [(checked)]="isEnabled" />
<sui-toggle-button [checked]="true" onLabel="Selected" />

Labels

Use offLabel and onLabel to customize the text shown for each state. 

<sui-toggle-button offLabel="Disabled" onLabel="Enabled" />
<sui-toggle-button offLabel="Unsubscribed" onLabel="Subscribed" [(checked)]="isSubscribed" />

Controlled state

Use [(checked)] to bind the Boolean state. External state changes are reflected by the component. 

<sui-toggle-button offLabel="Inactive" onLabel="Active" [(checked)]="isEnabled" />
<button (click)="isEnabled.set(true)">Set active</button>

Variants

Toggle buttons support the same variants as regular buttons: outlined, soft, dash, text, and link.

Available sizes are xs, sm, md, lg, and xl.

Shapes

Available shapes are default, fluid, square, and circle. 

<sui-toggle-button shape="fluid" />
<sui-toggle-button shape="square" ariaLabel="Toggle state">
  <ng-template suiToggleButtonOff>...</ng-template>
  <ng-template suiToggleButtonOn>...</ng-template>
</sui-toggle-button>

Custom state templates

Use suiToggleButtonOff and suiToggleButtonOn to replace the content of either state.

Not favorite Favorite Unavailable Available 
<sui-toggle-button [(checked)]="isFavorite" ariaLabel="Favorite item">
  <ng-template suiToggleButtonOff>
    Not favorite
  </ng-template>
  <ng-template suiToggleButtonOn>
    Favorite
  </ng-template>
</sui-toggle-button>

Custom button template

Use suiToggleButton to replace the complete internal button. Its context exposes the current state as the implicit value as well as checked, disabled, loading, and toggle.

State: {{ hasCustomButton() }} 
<sui-toggle-button [(checked)]="value">
  <ng-template
    suiToggleButton
    let-checked
    let-disabled="disabled"
    let-loading="loading"
    let-toggle="toggle"
  >
    <button
      [disabled]="disabled"
      [attr.aria-pressed]="checked"
      (click)="toggle()"
    >
      {{ '{{' }} checked ? 'On' : 'Off' {{ '}}' }}
    </button>
  </ng-template>
</sui-toggle-button>

States

disabled prevents interaction. loading exposes busy state and prevents toggling.

Disabled

Loading

<sui-toggle-button disabled />

Angular forms

Toggle buttons implement ControlValueAccessor and can be used with reactive and template-driven forms.

Form value: {{ notificationControl.value }} 

<sui-toggle-button [formControl]="notificationControl" offLabel="Disabled" onLabel="Enabled" />

Accessibility

The component uses a native button and communicates its state through aria-pressed. Provide ariaLabel when the rendered content does not provide a stable accessible name. 

<sui-toggle-button shape="square" ariaLabel="Enable notifications">...</sui-toggle-button>
