Input Wrapper

Place icons, text, badges, or keyboard hints inside one input surface while the nested input remains native.

Icons and keyboard hints

Apply suiInputWrapperControl to the nested input. A wrapping label gives the control its accessible name when visible text is present; icon-only compositions still need an accessible name.

Query: {{ searchForm.query().value() || 'Empty' }}

<label suiInputWrapper>
  <svg aria-hidden="true">...</svg>
  <input suiInputWrapperControl type="search" aria-label="Search" />
  <kbd suiKbd>⌘ K</kbd>
</label>

Text, icons, and badges

Content before or after the nested control becomes a prefix or suffix without extra component APIs. 

<label suiInputWrapper>
  Path
  <input suiInputWrapperControl placeholder="src/app/" />
  <span suiBadge>Optional</span>
</label>

Repository filters

Semantic and invalid states retain the same dimensions while native disabled behavior remains available. 

<label suiInputWrapper>...</label>
<label suiInputWrapper severity="error" invalid>...</label>
