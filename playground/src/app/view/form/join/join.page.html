Join

Visually connect related elements while keeping each child’s own behavior and semantics.

Horizontal composition

Apply suiJoin to the container and suiJoinItem to every child.

<div suiJoin>
  <button suiButton suiJoinItem>Previous</button>
  <button suiButton suiJoinItem>Next</button>
</div>

Vertical composition

orientation accepts horizontal or vertical. Join is visual only, so add an appropriate group role and accessible name when the children form one logical control. 

<div suiJoin orientation="vertical" role="group" aria-label="View options">...</div>
