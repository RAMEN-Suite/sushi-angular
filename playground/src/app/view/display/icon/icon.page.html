Icons

SUSHI uses @lucide/angular for icon examples and component defaults. Import only the icons you need and use them as standalone Angular components. Feel free to use any library you would like to.

Standalone icons

Import Lucide icons directly into the component and use them as SVG directives in the template. 

import { LucideDownload, LucideSearch, LucideSettings, LucideTrash2 } from '@lucide/angular';
@Component({
  imports: [LucideSearch, LucideSettings, LucideDownload, LucideTrash2],
})
export class IconPage {}
<svg class="size-5" lucideSearch></svg>
<svg class="size-5" lucideSettings></svg>
<svg class="size-5" lucideDownload></svg>
<svg class="size-5" lucideTrash2></svg>

Icons in buttons

Combine Lucide icons with suiButton. Use normal Tailwind utilities for size, spacing, and alignment. 

<button suiButton type="button">
  <svg class="size-4" lucidePlus></svg>
  Add item
</button>
<button suiButton type="button" shape="square" aria-label="Open settings">
  <svg class="size-4" lucideSettings></svg>
</button>
