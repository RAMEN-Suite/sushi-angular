Keyboard key

Use suiKbd to display keyboard shortcuts and individual keys.

Basic usage

Render a single key with the semantic <kbd> element.

K
<kbd suiKbd>K</kbd>

Sizes

Use five size steps from extra small through extra large.

XsmallSmallMediumLargeXlarge 
<kbd suiKbd size="xs">Xsmall</kbd>
<kbd suiKbd size="sm">Small</kbd>
<kbd suiKbd size="md">Medium</kbd>
<kbd suiKbd size="lg">Large</kbd>
<kbd suiKbd size="xl">Xlarge</kbd>

In text and key combinations

Keys remain inline with prose and can be combined into shortcuts.

Press F to pay respects.

ctrl + shift + del
Press <kbd suiKbd size="sm">F</kbd> to pay respects.
<kbd suiKbd>ctrl</kbd> + <kbd suiKbd>shift</kbd> + <kbd suiKbd>del</kbd>

Function and arrow keys

Arrange function and directional keys in the same layout users recognize from a keyboard.

⌘⌥⇧⌃
▲◀︎▶︎▼ 
<kbd suiKbd>⌘</kbd> <kbd suiKbd>⌥</kbd> <kbd suiKbd>⇧</kbd> <kbd suiKbd>⌃</kbd>

Press interaction

Keys include a pointer cursor and a small physical press response. Press and hold any key to try it.

WASDSpace 
<kbd suiKbd>W</kbd>
