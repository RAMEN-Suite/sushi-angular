Spinner

Use suiSpinner to indicate an ongoing operation. Spinners support multiple animation types and sizes and inherit their color from the surrounding text.

Basic usage

Apply suiSpinner to a <span>. The default type is spinner and the default size is md.

Loading 
<span suiSpinner></span>
<span class="inline-flex items-center gap-2">
  <span suiSpinner size="sm"></span>
  Loading
</span>

Types

Available types are spinner, dots, ring, ball, bars, and infinity.

Dots
Ring
Ball
Bars
Infinity 
<span suiSpinner type="spinner"></span>
<span suiSpinner type="dots"></span>
<span suiSpinner type="ring"></span>
<span suiSpinner type="ball"></span>
<span suiSpinner type="bars"></span>
<span suiSpinner type="infinity"></span>

Sizes

Available sizes are xs, sm, md, lg, and xl. 

<span suiSpinner size="xs"></span>
<span suiSpinner size="sm"></span>
<span suiSpinner size="md"></span>
<span suiSpinner size="lg"></span>
<span suiSpinner size="xl"></span>

Colors

Spinners use currentColor. Apply normal text-color utilities to the spinner or a surrounding element. 

<span suiSpinner class="text-primary"></span>
<span suiSpinner class="text-success"></span>
<span suiSpinner class="text-error"></span>

Buttons

Combine suiSpinner with suiButton. The button’s loading input exposes aria-busy; the spinner remains decorative. 

<button suiButton type="button" loading>
  <span suiSpinner size="sm"></span>
  Loading
</button>

Accessibility

The spinner itself is decorative. Provide a visible or visually hidden status message on a surrounding element when no other text describes the operation.

<div role="status" aria-live="polite">
  <span suiSpinner></span>
  <span>Loading results</span>
</div>
