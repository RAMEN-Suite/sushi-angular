Code

Use <sui-code> for terminal-like code blocks and documentation examples. Code blocks support line prefixes, configurable copy feedback, custom icons, and a completely replaceable copy button.

Basic usage

Add suiCodeLine to each code line. Set [copyable]="false" to hide the copy button. 

npm install @ramen-suite/sushi
Package installed
 
const enabled: boolean = true;
 
<sui-code>
  <pre suiCodeLine prefix="$"><code>npm install @ramen-suite/sushi</code></pre>
</sui-code>
<sui-code [copyable]="false">...</sui-code>

Line prefixes and styling

Use prefix for line numbers, prompts, or output markers. Normal utility classes can be applied directly to a code line. 

import { SuiButton } from '@ramen-suite/sushi';
import { SuiCode } from '@ramen-suite/sushi';
const experimental: boolean = true;
 
<pre suiCodeLine prefix="1">...</pre>
<pre suiCodeLine prefix="2" class="bg-primary text-primary-content">...</pre>

Copy feedback

The cooldown input controls how long the copied state remains visible. Use buttonShape to change the control shape, buttonAriaLabel to provide an accessible name, and the state templates to replace its content.

Copy Copied 
ng serve playground
 
<sui-code [cooldown]="2000" [buttonShape]="null" buttonAriaLabel="Copy command">
  <ng-template suiCodeButtonOff>Copy</ng-template>
  <ng-template suiCodeButtonOn>Copied</ng-template>
  ...
</sui-code>

Custom copy button

Use suiCodeCopyButton to replace the complete copy control. Its context exposes the copy action as the implicit value and through copy, plus the reactive copied signal. 

const framework: string = 'Angular';
const library: string = 'SUSHI';
 
<sui-code>
  <ng-template suiCodeCopyButton let-copy let-copied="copied">
    <button
      suiButton
      type="button"
      [attr.aria-disabled]="copied()"
      (click)="copy()"
    >
      {{ '{{' }} copied() ? 'Copied' : 'Copy' {{ '}}' }}
    </button>
  </ng-template>
  ...
</sui-code>
