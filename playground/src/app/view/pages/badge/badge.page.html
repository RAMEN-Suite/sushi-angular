Badge

Use suiBadge on inline elements such as <span>. Badges support severities, variants, and sizes.

Basic usage

The default badge uses severity="primary" and size="md".

Primary Secondary Success Error 
<span suiBadge>Primary</span>
<span suiBadge severity="secondary">Secondary</span>
<span suiBadge severity="success" variant="soft">Success</span>
<span suiBadge severity="error" variant="outlined">Error</span>

Severities

The severity input controls the semantic color.

Primary Secondary Accent Neutral Success Info Warning Error 
<span suiBadge severity="primary">Primary</span>
<span suiBadge severity="secondary">Secondary</span>
<span suiBadge severity="accent">Accent</span>
<span suiBadge severity="neutral">Neutral</span>
<span suiBadge severity="success">Success</span>
<span suiBadge severity="info">Info</span>
<span suiBadge severity="warning">Warning</span>
<span suiBadge severity="error">Error</span>

Variants

The default variant is solid. Available variants are outlined, soft, dash, and ghost.

Solid Outlined Soft Dash Ghost
Solid Outlined Soft Dash Ghost 
<span suiBadge>Solid</span>
<span suiBadge variant="outlined">Outlined</span>
<span suiBadge variant="soft">Soft</span>
<span suiBadge variant="dash">Dash</span>
<span suiBadge variant="ghost">Ghost</span>

Sizes

Available sizes are xs, sm, md, lg, and xl.

XS SM MD LG XL 
<span suiBadge size="xs">XS</span>
<span suiBadge size="sm">SM</span>
<span suiBadge size="md">MD</span>
<span suiBadge size="lg">LG</span>
<span suiBadge size="xl">XL</span>

Common patterns

Badges work well for counts, metadata, publication states, and lightweight labels.

Counts

12 24 99+ 3

Metadata

Person Place Institution Annotation

States

Published Draft Review Deprecated 
<span suiBadge>12</span>
<span suiBadge severity="neutral" variant="soft">Person</span>
<span suiBadge severity="success">Published</span>

Badges in buttons

Badges can be combined with suiButton to show counts inside actions.

<button suiButton type="button" severity="primary">
  Messages
  <span suiBadge severity="secondary" size="sm">12</span>
</button>
