Divider

Use suiDivider to separate content horizontally or vertically. Dividers support severity, placement, and orientation.

Basic usage

The default divider is horizontal and can be used with or without label content.

Section
Secondary
<div suiDivider></div>
<div suiDivider>Section</div>
<div suiDivider severity="secondary">Secondary</div>

Severities

The severity input controls the semantic color.

Primary
Secondary
Accent
Neutral
Success
Info
Warning
Error
<div suiDivider severity="primary">Primary</div>
<div suiDivider severity="secondary">Secondary</div>
<div suiDivider severity="accent">Accent</div>
<div suiDivider severity="success">Success</div>

Horizontal placement

The placement input controls the label position on horizontal dividers.

Start
Center
End
<div suiDivider placement="start">Start</div>
<div suiDivider placement="center">Center</div>
<div suiDivider placement="end">End</div>

Vertical orientation

Use orientation="vertical" inside horizontal layouts.

Left
Right
<div class="flex h-32">
  <div>Left</div>
  <div suiDivider orientation="vertical"></div>
  <div>Right</div>
</div>
