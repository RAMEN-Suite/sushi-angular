Card

Use suiCard to group related content in a visual container. Cards support variants, sizes, body content, titles, and action areas.

Basic usage

The default card uses variant="border" and size="md".

Cards are useful for summaries, grouped metadata, forms, examples, and contextual actions.

<section suiCard>
  <div suiCardBody>
    <h2 suiCardTitle>Card title</h2>
    <p>Card content</p>
  </div>
</section>

Variants

Available variants are plain, border, and dash.

Plain

Simple card surface.

Border

Default Sushi card.

Dash

Dashed visual grouping.

<section suiCard variant="plain">...</section>
<section suiCard variant="border">...</section>
<section suiCard variant="dash">...</section>

Sizes

Available sizes are xs, sm, md, lg, and xl.

Small

Compact content.

Medium

Default card size.

Large

More spacious content.

<section suiCard size="sm">...</section>
<section suiCard size="md">...</section>
<section suiCard size="lg">...</section>

Actions

Use suiCardActions for button rows. Alignment can be adjusted with Tailwind utilities.

Order Summary

Design Service $120.00
Hosting $30.00
Total $150.00 
<section suiCard>
  <div suiCardBody>
    <h3 suiCardTitle>Order Summary</h3>
    <div suiDivider></div>
    <div suiCardActions>
      <button suiButton type="button">Pay</button>
    </div>
  </div>
</section>

Media

Cards can include native media elements without additional template APIs.

Manuscript preview

Combine media, metadata, and actions with normal HTML and Tailwind utilities.

<article suiCard class="overflow-hidden">
  <figure>...</figure>
  <div suiCardBody>...</div>
</article>
