Button

Use suiButton on native <button> and <a> elements. Buttons support severities, variants, sizes, shapes, disabled state, and loading state.

Basic usage

The directive works on native buttons and anchors.

Anchor Router Link 
<button suiButton type="button">Button</button>
<button suiButton type="submit" severity="secondary">Submit</button>
<a suiButton href="https://example.com">Anchor</a>
<a suiButton routerLink="/button" severity="accent" variant="outlined">Router Link</a>

Severities

The severity input controls the semantic color.

<button suiButton severity="primary">Primary</button>
<button suiButton severity="secondary">Secondary</button>
<button suiButton severity="accent">Accent</button>
<button suiButton severity="neutral">Neutral</button>
<button suiButton severity="success">Success</button>
<button suiButton severity="info">Info</button>
<button suiButton severity="warning">Warning</button>
<button suiButton severity="error">Error</button>

Variants

The default variant is solid. Available variants are outlined, soft, dash, text, and link.

Primary

Secondary

<button suiButton>Solid</button>
<button suiButton variant="outlined">Outlined</button>
<button suiButton variant="soft">Soft</button>
<button suiButton variant="dash">Dash</button>
<button suiButton variant="text">Text</button>
<button suiButton variant="link">Link</button>

Status severities

Use status severities for contextual or destructive actions.

<button suiButton severity="success">Success</button>
<button suiButton severity="info">Info</button>
<button suiButton severity="warning">Warning</button>
<button suiButton severity="error">Error</button>

Sizes

Available sizes are xs, sm, md, lg, and xl. 

<button suiButton size="xs">XS</button>
<button suiButton size="sm">SM</button>
<button suiButton size="md">MD</button>
<button suiButton size="lg">LG</button>
<button suiButton size="xl">XL</button>

Shapes

Available shapes are default, fluid, square, and circle.

Default and fluid

Square and circle

<button suiButton>Default</button>
<button suiButton shape="fluid">Fluid</button>
<button suiButton shape="square" aria-label="Square button">S</button>
<button suiButton shape="circle" aria-label="Circle button">C</button>

States

disabled prevents interaction. loading exposes busy state with aria-busy.

Disabled

Disabled Anchor

Loading

  <span class="loading loading-spinner loading-sm" aria-hidden="true"></span>
