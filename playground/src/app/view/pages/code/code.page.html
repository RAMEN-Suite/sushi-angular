Code

Use <sui-code> for documentation examples and terminal-like code blocks. Code blocks support line prefixes and copying.

Basic usage

Use <sui-code> as a container and suiCodeLine on each <pre> line. Set [copyable]="false" to hide the copy button. 

npm install @ramen-suite/sushi
installing...
done
 
npm install @ramen-suite/sushi
copy button disabled
 
<sui-code>
  <pre suiCodeLine prefix="$"><code>npm install @ramen-suite/sushi</code></pre>
</sui-code>
<sui-code [copyable]="false">
  <pre suiCodeLine prefix="$"><code>copy button disabled</code></pre>
</sui-code>

Line prefixes

Use prefix for line numbers, shell prompts, or output markers.

import { SuiButton } from '@ramen-suite/sushi';
import { SuiBadge } from '@ramen-suite/sushi';
import { SuiCard } from '@ramen-suite/sushi';
 
<pre suiCodeLine prefix="1"><code>...</code></pre>
<pre suiCodeLine prefix="$"><code>...</code></pre>
<pre suiCodeLine prefix=">"><code>...</code></pre>

Line highlighting

Use normal utility classes on suiCodeLine for highlighting.

import { SuiButton } from '@ramen-suite/sushi';
import { SuiBadge } from '@ramen-suite/sushi';
import { SuiCard } from '@ramen-suite/sushi';
 
<pre suiCodeLine class="bg-primary text-primary-content"><code>...</code></pre>
<pre suiCodeLine class="italic"><code>...</code></pre>
<pre suiCodeLine class="text-warning"><code>...</code></pre>

Custom copy icons

Use suiCodeCopyIcon and suiCodeCopiedIcon to override the default copy and copied icons.

Copy Copied 
npm install @ramen-suite/sushi
ng serve playground
 
<sui-code>
  <ng-template suiCodeCopyIcon>
    <span class="text-sm">Copy</span>
  </ng-template>
  <ng-template suiCodeCopiedIcon>
    <span class="text-sm">Copied</span>
  </ng-template>
  <pre suiCodeLine prefix="$"><code>npm install @ramen-suite/sushi</code></pre>
</sui-code>
