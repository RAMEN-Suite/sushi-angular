Lightbox

Open individual images in a focused, zoomable full-screen viewer.

Component

Native and optimized images

Add suiLightbox directly to a native image. It also composes with Angular's NgOptimizedImage and reuses its resolved source, dimensions, and alternative text automatically.

Programmatic control

Use the component API only when a separate action must call show() or close(). The image Directive remains the shorter default.

Viewer settings

Keep configuration local to the image with zoom, wheelToZoom, description, and ariaLabel.
