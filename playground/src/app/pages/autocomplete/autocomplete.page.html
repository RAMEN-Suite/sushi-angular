Autocomplete

Suggest matching values while a user types, with keyboard navigation and optional free text.

Component Signal Forms Angular Aria Angular CDK Templates

Basic usage and forms

Keep the popup closed until typing by default; use forceSelection when only listed values are valid. Escape closes the suggestions and discards an unconfirmed forced value.

Filtering and templates

Suggestions open after the query reaches minQueryLength. Replace matching through filterWith and customize meaningful visual regions.

Asynchronous suggestions

queryChange fires after the configurable delay. Loading, empty, and error templates keep remote states replaceable.

Sizes and states

All sizes share the same behavior. Search values are always clearable, while loading, disabled, and invalid states follow the shared form-control conventions.
