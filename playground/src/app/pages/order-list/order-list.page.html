Order List

Reorder rich rows with a handle, a movement menu or keyboard shortcuts.

Component Signal Forms Angular Aria Angular CDK Templates

Basic

Bind the complete collection directly or through Signal Forms. Sorting moves one complete row at a time.

Drag and drop

Drag only from the leading handle. Click the same handle for movement actions. Row content keeps its own interaction.

Disabled

Disabled makes the collection inert. Use reorderable=false to keep row controls usable while stopping movement.

Save or cancel an order

Choose Sort properties, move a property using its handle, then save the new order or cancel to restore the saved order.
