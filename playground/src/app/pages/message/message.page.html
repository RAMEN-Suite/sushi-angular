Message

Use suiMessage for contextual feedback and important information.

Severities

Use informational, success, warning, and error colors to communicate the message’s meaning.

There is a new update available.
12 unread messages. Tap to see.
Your purchase has been confirmed!
Warning: Invalid email address!
Error! Task failed successfully.
<div suiMessage>There is a new update available.</div>
<div suiMessage severity="success">Your changes were saved.</div>

Variants and actions

Messages support soft, outline, and dash styles. suiMessageActions groups related controls and aligns them at the end of a horizontal message.

Unsaved changes will be lost.
Outlined informational message.
Dashed error message.
<div suiMessage severity="warning" variant="soft" role="alert">
  <span>Unsaved changes will be lost.</span>
  <div suiMessageActions>
    <button suiButton size="sm">Save</button>
  </div>
</div>

Orientation

Choose a horizontal layout for wide areas or a centered vertical layout for narrow surfaces.

Horizontal message
Vertical message 
<div suiMessage orientation="horizontal">...</div>
<div suiMessage orientation="vertical">...</div>
