Input

Add consistent sizing, semantic colors, and form state to native text controls without replacing browser behavior.

Directive Native element Signal Forms

Basic usage and forms

Use a native label and input type. Invalid controls receive aria-invalid after interaction.

Sizes and semantic colors

Choose one of five control sizes and apply a semantic color only when the surrounding workflow benefits from that meaning.

Search and account fields

Compose a native input with existing field surfaces instead of adding icon and shortcut APIs to suiInput.

Native states

Continue to use native attributes such as type, disabled, readonly, required, autocomplete, and ARIA references. Set invalid for an explicit invalid presentation.

Native input types

The directive styles every text-field-like native type without changing its browser behavior. Checkbox, radio, file, and range use their dedicated controls.

Data list suggestions

Connect a native datalist through the input’s list attribute for browser-provided suggestions.
