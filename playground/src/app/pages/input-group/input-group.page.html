Input Group

Join controls, actions, and non-interactive add-ons into one visually connected composition.

Prefix, suffix, and actions

suiInputGroupAddon represents text or decoration; suiJoinItem connects interactive children.

https://
.com 
<div suiInputGroup>
  <span suiInputGroupAddon>https://</span>
  <input suiInput suiJoinItem aria-label="Domain" />
  <button suiButton suiJoinItem>Open</button>
</div>

Multiple and nested items

Groups may contain several controls and actions. Add an accessible name to each control; the visual connection does not replace labels.

BudgetEUR 
<div suiInputGroup>
  <span suiInputGroupAddon>Budget</span>
  <input suiInput suiJoinItem type="number" aria-label="Amount" />
  <select class="select join-item" aria-label="Period">...</select>
  <button suiButton suiJoinItem>Apply</button>
</div>

Vertical and responsive

orientation accepts horizontal, vertical, or responsive. Responsive groups stack on narrow screens and switch to a horizontal join from the medium breakpoint. 

<div suiInputGroup orientation="vertical">...</div>
<div suiInputGroup orientation="responsive">...</div>

Custom outer corners

Override only the first and last item radius when a composition needs a different silhouette. 

<input suiInput suiJoinItem class="rounded-l-full" />
<button suiButton suiJoinItem class="rounded-r-full">Send</button>
