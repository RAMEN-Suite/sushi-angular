Menu

Present related application commands with predictable keyboard behavior. The same command menu can remain visible, open from a button, or appear at a context-menu gesture.

Component Angular Aria Angular CDK Templates

Inline command menu

Use an inline menu when a small set of application commands should remain visible beside the content they affect.

Active state and custom icons

Store any icon component in an extended item model and render it through the item template. The active state identifies the current application mode.

Split-button dropdown

A menu becomes a dropdown when a button presents it in an overlay. The primary button keeps the common action immediately available.

Context menu

Attach the context trigger to the surface whose commands should open at the pointer. Keyboard users receive the same menu with Shift + F10 or the context-menu key.

Nested commands

Keep related secondary commands in submenus. Hover, click, or use the arrow keys to move through every level.

Groups and templates

Enrich repeated entries and structural regions while the menu keeps ownership of interaction.

Disabled states

Disable one unavailable command or the complete menu without removing useful content from view.
