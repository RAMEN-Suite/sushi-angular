Icons

Bring the icon system that fits your product. Lucide is the recommended integration used by SUSHI's defaults and examples.

Integration

Recommended: Lucide

SUSHI uses Lucide for built-in icons where a component needs a default. Consumers can project or template another SVG icon system wherever the component exposes customization. Install Lucide only when you want to use these defaults or follow the examples below.

  1. 1

    Install when needed

    npm install @lucide/angular
  2. 2

    Import selectively

    Add individual directives such as LucideSearch to component imports.

  3. 3

    Keep semantics native

    Hide decorative SVGs and label the surrounding control instead.

Standalone and actionable icons

Icons inherit the current text color and size; icon-only controls still require an accessible name.
