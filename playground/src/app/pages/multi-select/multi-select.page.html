Basic usage and forms

Up to three selected labels are shown as a comma-separated list by default. Larger selections are summarized as the first label plus the remaining count; maxSelectedLabels adjusts the threshold.

Selected value and option templates

Use the selected-items template for a custom compact summary and the item template for richer option content.

Grouped options

Group adjacent options into readable categories while keyboard navigation continues through selectable rows only.

Select all, templates, and states

Select-all remains opt-in. Header context, footer, icons, loading, empty, disabled, invalid, filled, size, and clear behavior remain configurable.
