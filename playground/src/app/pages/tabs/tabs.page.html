Tabs

Switch between related views with accessible keyboard navigation, configurable activation, lazy panels, and responsive layouts.

Basic usage

Each suiTab template defines its value, visible label, and panel content. Bind value to control the active panel.

Profile

Update your public name and biography.

Security

Review passwords and active sessions.

 Billing is unavailable. 
<sui-tabs [(value)]="activeTab" ariaLabel="Account sections">
  <ng-template suiTab value="profile" label="Profile">...</ng-template>
  <ng-template suiTab value="security" label="Security">...</ng-template>
  <ng-template suiTab value="billing" label="Billing" disabled>...</ng-template>
</sui-tabs>

Styles

variant supports plain, border, lift, and box presentations.

@for (variant of variants; track variant) {
{{ variant }} Overview content. Recent activity.
} 
<sui-tabs value="overview" variant="plain">...</sui-tabs>
<sui-tabs value="overview" variant="border">...</sui-tabs>
<sui-tabs value="overview" variant="lift">...</sui-tabs>
<sui-tabs value="overview" variant="box">...</sui-tabs>

Sizes

size changes the tab controls without affecting panel content.

@for (size of sizes; track size) { Selected {{ size }} tab. Second tab. }

<sui-tabs value="one" size="md">...</sui-tabs>
<sui-tabs value="one" size="lg">...</sui-tabs>
<sui-tabs value="one" size="xl">...</sui-tabs>

Activation and focus

Follow mode selects as focus moves. Explicit mode waits for Enter or Space. Wrapping and disabled-tab focus remain configurable.

Preview the current project. Review recent changes. Publishing is unavailable. 
<sui-tabs
  value="preview"
  selectionMode="explicit"
  focusMode="roving"
  [wrap]="false"
  [softDisabled]="false"
>...</sui-tabs>

Orientation, placement, and panel lifetime

Vertical tabs use Up and Down arrows. The list may sit below its panels, while preserveContent controls whether an inactive panel remains instantiated.

General settings. Team settings. Lazily recreated advanced settings.
The tab list appears below this panel. Additional details. Disabled group. Second panel.

<sui-tabs value="summary" variant="lift" placement="bottom">...</sui-tabs>
<sui-tabs value="one" disabled>...</sui-tabs>
<ng-template suiTab value="advanced" label="Advanced" [preserveContent]="false">...</ng-template>
